# Security policy

Report vulnerabilities privately to the repository owner. Do not include applicant names, contact details, resumes, application answers, access tokens, database contents, screenshots of private pages, or other personal data in issues, pull requests, logs, or proof-of-concept artifacts.

If reproduction requires private data, provide a sanitized fixture that cannot be linked to a real person. Rotate any credential that is accidentally exposed and remove it from repository history before publishing.
